# Goals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Weekly, monthly and yearly goals (personal or Household) in `Goals/`, linked to tasks, with computed progress and an end-of-period review page in `Reviews/`.

**Architecture:** A new module `tools/goals.py` holds everything about goals (periods, storage, progress, lint rules, carry, review) and registers the `goal`, `goals` and `review` commands on `tools/tasks.py`'s argument parser. `tasks.py` keeps its role and only gains small hooks (link tasks to goals, lint, list, find). Goal files reuse the task file format (frontmatter + `## Notes` + `## Log`) so the existing field-by-field merge driver handles them.

**Tech Stack:** Python 3.9+ standard library only; `unittest` end-to-end tests in `tests/test_vault.py` (each test copies the template to a temp dir and runs the tools as subprocesses); Obsidian Bases (`.base` YAML) for the view.

**Spec:** `docs/superpowers/specs/2026-11-15-goals-design.md`

## Global Constraints

- Standard library only; must run on Python 3.9 (no `match`, no `X | Y` at runtime outside annotations — files use `from __future__ import annotations`).
- Works on macOS, Linux and Windows: paths via `pathlib`, files read/written with `encoding="utf-8"`.
- Never invent task fields: tasks link to goals only through the existing `projects` field.
- Goal statuses exactly: `active` `achieved` `partial` `missed` `dropped`. Periods exactly: `YYYY`, `YYYY-MM`, `YYYY-Www` (ISO weeks, Monday–Sunday).
- Owner of shared goals is the People note `Household`; `Household` must never be a task `assignee` (lint error).
- Goals carry `tags: [goal]` and never `task`.
- Every changing command commits and syncs via the existing `sync_after_change` (support `--no-sync`).
- This repo is the public template: only `example: true` goals go into `Goals/`; `Goals/`, `Reviews/` are user folders (never in `.template-files`).
- Run the whole suite with `python3 -m unittest discover tests` (≈90 s). Run one test with `python3 -m unittest tests.test_vault.TestGoals.test_name -v`.

## Refinements to the spec (decided while planning)

1. Goals also get `dateModified` (maintained by the tool) — the merge driver needs it to pick the newer edit.
2. `Goals/` and `Reviews/` are created on first write by the tool, not by setup (git does not track empty folders). Setup/update only ensure `People/Household.md`.
3. A goal whose title already has a file gets the period in its file name: `Goals/Gym three times (2026-W48).md` (also used by `goal carry`). The `title` field keeps the plain title.
4. A recurring task counts the occurrences inside the period of the goal it is linked to (the shortest one if several), clipped to the goal being measured.
5. Summary wording: `"0 of 1 month goal achieved"` / `"2 of 3 week goals achieved"`; percentages are floored.
6. Dropped goals show the icon `➖` in `goals` output and are struck through on review pages.

```python
"""Goals for a week, a month or a year, linked to tasks, and the review page at
the end of each period. Part of tools/tasks.py (the `goal`, `goals` and
`review` commands); standard library only.

A goal is a file in Goals/ with the same shape as a task (frontmatter, Notes,
Log). Tasks count toward a goal by listing it in `projects`, the way they
list a project. Goals form a tree through `parent`: week -> month -> year.
"""
from __future__ import annotations

import datetime as dt
import re
import sys
from pathlib import Path

import tasks as T

HOUSEHOLD = "Household"
GOAL_STATUSES = ["active", "achieved", "partial", "missed", "dropped"]
VERDICTS = GOAL_STATUSES[1:]
LEVELS = {"year": 0, "month": 1, "week": 2}
PERIOD_RE = re.compile(r"^(\d{4})(?:-(\d{2})|-W(\d{2}))?$")
PERIOD_HELP = "period must be YYYY, YYYY-MM or YYYY-Www (an ISO week, e.g. 2026-W47)"


# --- periods ----------------------------------------------------------------

def parse_period(value) -> tuple[str, dt.date, dt.date] | None:
    """(kind, first day, last day) of `2026`, `2026-11` or `2026-W47`; None if invalid."""
    match = PERIOD_RE.match(str(value or "").strip())
    if not match:
        return None
    year = int(match.group(1))
    if match.group(2):
        month = int(match.group(2))
        if not 1 <= month <= 12:
            return None
        first = dt.date(year, month, 1)
        return "month", first, first.replace(day=T.last_day(first))
    if match.group(3):
        try:
            first = dt.date.fromisocalendar(year, int(match.group(3)), 1)
        except ValueError:  # week 0, or week 53 in a 52-week year
            return None
        return "week", first, first + dt.timedelta(days=6)
    return "year", dt.date(year, 1, 1), dt.date(year, 12, 31)


def period_of(kind: str, d: dt.date) -> str:
    """The year, month or ISO week that contains `d`."""
    if kind == "year":
        return str(d.year)
    if kind == "month":
        return f"{d.year}-{d.month:02d}"
    year, week, _ = d.isocalendar()
    return f"{year}-W{week:02d}"


def contains(outer: str, inner: str) -> bool:
    """Whether a goal for `outer` can be the parent of a goal for `inner`: a
    longer period that holds it. A week belongs to the month and year of its
    Thursday, as ISO weeks do (2026-W49, 30 Nov - 6 Dec, is in December)."""
    a, b = parse_period(outer), parse_period(inner)
    if not a or not b or LEVELS[a[0]] >= LEVELS[b[0]]:
        return False
    anchor = b[1] + dt.timedelta(days=3) if b[0] == "week" else b[1]
    return period_of(a[0], anchor) == str(outer).strip()


def default_period(kind: str, today: dt.date | None = None) -> str:
    """The period to review: the one that just ended, or the current one when
    it ends within two days."""
    today = today or dt.date.today()
    current = period_of(kind, today)
    _, first, last = parse_period(current)
    if (last - today).days <= 2:
        return current
    return period_of(kind, first - dt.timedelta(days=1))


def current_periods(today: dt.date | None = None) -> list[str]:
    today = today or dt.date.today()
    return [period_of(kind, today) for kind in ("week", "month", "year")]
```

```python
# --- goal files ---------------------------------------------------------------

def load_goals() -> list[dict]:
    goals = []
    for path in sorted(T.GOALS.rglob("*.md")) if T.GOALS.is_dir() else []:
        lines, _ = T.split(path.read_text(encoding="utf-8"))
        if lines is None:
            continue
        meta = T.parse(lines)
        if "goal" not in T.as_list(meta.get("tags")):
            continue
        meta["_path"] = path
        goals.append(meta)
    return goals


def index_goals() -> dict[str, dict]:
    """Every goal by lower-case file name (what `[[links]]` point at)."""
    return {g["_path"].stem.lower(): g for g in load_goals()}


def title(g: dict) -> str:
    return g.get("title") or g["_path"].stem


def key(g: dict) -> str:
    return g["_path"].stem.lower()


def parent_key(g: dict) -> str:
    return T.name_of(g.get("parent") or "").lower()


def lookup_goal(name: str, goals: dict | None = None) -> dict | None:
    """The goal with this file name or title (ignoring case and punctuation), else None."""
    goals = index_goals() if goals is None else goals
    if T.name_of(name).lower() in goals:
        return goals[T.name_of(name).lower()]
    exact = [g for g in goals.values()
             if T.squash(name) in (T.squash(title(g)), T.squash(g["_path"].stem))]
    return exact[0] if len(exact) == 1 else None


def find_goal(name: str, goals: dict | None = None) -> dict:
    """Like lookup_goal, also accepting the only goal whose name contains `name`."""
    goals = index_goals() if goals is None else goals
    found = lookup_goal(name, goals)
    if found:
        return found
    near = [g for g in goals.values()
            if T.squash(name) and T.squash(name) in T.squash(g["_path"].stem)]
    if len(near) == 1:
        return near[0]
    hint = "; ".join(T.rel(g["_path"]) for g in near[:5]) or "no match"
    sys.exit(f"cannot pick one goal for {name!r}: {hint}")


def new_goal_path(name: str, period: str) -> Path:
    """Goals/<title>.md, or Goals/<title> (<period>).md when the title is taken."""
    base = T.file_name(re.sub(r"\s*\(\d{4}(?:-\d{2}|-W\d{2})?\)$", "", name.strip()), "Goal")
    path = T.GOALS / f"{base}.md"
    if path.exists():
        path = T.GOALS / f"{base} ({period}).md"
    n = 2
    while path.exists():
        path, n = T.GOALS / f"{base} ({period}) {n}.md", n + 1
    return path


def as_number(value) -> float | None:
    try:
        return float(str(value).strip())
    except (TypeError, ValueError):
        return None


def fmt(n: float) -> str:
    return str(int(n)) if n == int(n) else str(round(n, 2))


def number(value: str) -> str:
    n = as_number(value)
    if n is None:
        sys.exit(f"expected a number, got {value!r}")
    return fmt(n)


def check_period(value: str) -> str:
    if parse_period(value) is None:
        sys.exit(f"{PERIOD_HELP}; got {value!r}")
    return value.strip()


def save(path: Path, changes: dict, message: str | None = None) -> None:
    """Apply field changes to a goal, keep completedDate in step with the
    status, stamp dateModified and log what happened."""
    lines, body = T.split(path.read_text(encoding="utf-8"))
    if lines is None:
        sys.exit(f"{T.rel(path)} has no frontmatter")
    meta = T.parse(lines)
    status = changes.get("status")
    if status and status != "active" and not meta.get("completedDate") \
            and "completedDate" not in changes:
        changes["completedDate"] = dt.date.today().isoformat()
    elif status == "active" and meta.get("completedDate"):
        changes["completedDate"] = None
    for k, value in changes.items():
        lines = T.set_key(lines, k, value)
    lines = T.set_key(lines, "dateModified", T.now())
    if status:
        message = f"status -> {status}" + (f": {message}" if message else "")
    if message:
        body = T.add_log(body, message)
    T.write(path, lines, body)


def blocked_entry(g: dict) -> dict:
    return {"uid": T.link(g["_path"].stem), "reltype": "FINISHTOSTART"}


def checked_parent(name: str, period: str, goals: dict) -> dict:
    parent = find_goal(name, goals)
    if not contains(str(parent.get("period") or ""), period):
        sys.exit(f"{title(parent)} ({parent.get('period')}) cannot be the parent of a "
                 f"{period} goal: the parent must be a longer period that contains {period}")
    return parent


# --- commands -----------------------------------------------------------------

def cmd_goal_new(args) -> None:
    period = check_period(args.period)
    owner = T.person(args.owner)
    goals = index_goals()
    lines = (T.render("title", args.title.strip()) + T.render("type", "goal")
             + T.render("period", period) + T.render("owner", T.link(owner))
             + T.render("status", "active"))
    if args.parent:
        lines += T.render("parent", T.link(checked_parent(args.parent, period, goals)["_path"].stem))
    if args.blocked_by:
        lines += T.render("blockedBy", [blocked_entry(find_goal(args.blocked_by, goals))])
    if args.target is not None:
        lines += T.render("target", number(args.target)) + T.render("progress", "0")
    if args.unit:
```

```python
# --- progress -----------------------------------------------------------------

ICONS = {"achieved": "✅", "partial": "🟡", "missed": "❌", "dropped": "➖"}


def children(g: dict, goals: dict) -> list[dict]:
    return [c for c in goals.values() if parent_key(c) == key(g)]


def tree(g: dict, goals: dict) -> list[dict]:
    """The goal and every goal under it, each once (a loop in `parent` can't hang it)."""
    out, todo, seen = [], [g], set()
    while todo:
        x = todo.pop(0)
        if key(x) in seen:
            continue
        seen.add(key(x))
        out.append(x)
        todo += children(x, goals)
    return out


def goal_links(t: dict) -> set[str]:
    return {T.name_of(p).lower() for p in T.as_list(t.get("projects"))}


def linked_tasks(keys: set[str], tasks: dict) -> list[dict]:
    return [t for t in tasks.values() if goal_links(t) & keys]


def span(g: dict) -> tuple[dt.date, dt.date] | None:
    parsed = parse_period(g.get("period"))
    return (parsed[1], parsed[2]) if parsed else None


def occurrences(t: dict, first: dt.date, last: dt.date) -> int:
    """How many times a recurring task falls between first and last."""
    rule = T.parse_rule(str(t.get("recurrence") or ""))
    if rule is None:
        return 0
    anchor = rule.get("DTSTART") or T.day(t.get("scheduled")) or first
    until = re.sub(r"\D", "", rule.get("UNTIL", ""))[:8]
    end = min(last, dt.date(int(until[:4]), int(until[4:6]), int(until[6:8]))) if len(until) == 8 else last
    d = max(first, rule["DTSTART"]) if rule.get("DTSTART") else first
    count = 0
    while d <= end:
        count += T.on_rule(d, rule, anchor)
        d += dt.timedelta(days=1)
    return count


def when(t: dict) -> str:
    for k in ("due", "scheduled"):
        d = T.day(t.get(k))
        if d:
            late = ", missed" if d < dt.date.today() and t.get("status") not in T.CLOSED else ""
            return f" ({k} {str(t[k])[:10]}{late})"
    return ""


def progress(g: dict, goals: dict, tasks: dict) -> dict:
    """Tasks done of all (this goal's and every goal's under it), the number
    target and the child goals' verdicts. Never sets the goal's status."""
    members = {key(x): x for x in tree(g, goals)}
    outer = span(g)
    done = total = 0
    still: list[tuple[dict, str]] = []
    for t in linked_tasks(set(members), tasks):
        status = t.get("status")
        if status == "cancelled":
            continue
        if t.get("recurrence"):
            # Occurrences inside the period of the goal it counts toward (the
            # shortest one if several), within the period of this goal.
            spans = sorted((s for s in (span(members[k]) for k in goal_links(t) if k in members) if s),
                           key=lambda s: s[1] - s[0])
            if not spans or not outer:
                continue
            first, last = max(spans[0][0], outer[0]), min(spans[0][1], outer[1])
            finished = sum(1 for d in T.as_list(t.get("complete_instances"))
                           if T.day(d) and first <= T.day(d) <= last)
            expected = max(occurrences(t, first, last), finished)
            done, total = done + finished, total + expected
            if finished < expected and status not in T.CLOSED:
                still.append((t, f" ({finished}/{expected} this period)"))
        else:
            total += 1
            if status == "done":
                done += 1
            else:
                still.append((t, when(t)))
    kids = children(g, goals)
    kinds = [parse_period(c.get("period")) for c in kids]
    target, value = as_number(g.get("target")), as_number(g.get("progress") or 0)
    return {"done": done, "total": total, "open": sorted(still, key=lambda x: T.title_of(x[0])),
            "children": len(kids), "achieved": sum(1 for c in kids if c.get("status") == "achieved"),
            "child_kind": next((k[0] for k in kinds if k), ""),
            "number": (value or 0.0, target) if target is not None else None}


def summary(g: dict, p: dict) -> str:
    parts = []
    if p["number"]:
        value, target = p["number"]
        pct = int(100 * value / target) if target else 0
        unit = f" {g['unit']}" if g.get("unit") else ""
        parts.append(f"{fmt(value)}/{fmt(target)}{unit} ({pct}%)")
    if p["total"]:
        parts.append(f"tasks {p['done']}/{p['total']}")
    if p["children"]:
        plural = "s" if p["children"] != 1 else ""
        parts.append(f"{p['achieved']} of {p['children']} {p['child_kind']} goal{plural} achieved")
    return " · ".join(parts) or "no tasks linked"


def open_goal_blockers(g: dict, goals: dict) -> list[str]:
    return [b for b in T.blockers(g) if goals.get(b.lower(), {}).get("status") != "achieved"]


def icon(g: dict, p: dict, goals: dict) -> str:
    status = g.get("status") or "active"
    if status in ICONS:
        return ICONS[status]
    if open_goal_blockers(g, goals):
        return "⛔"
    moved = p["done"] or p["achieved"] or (p["number"] and p["number"][0] > 0)
    return "🟡" if moved else "⬜"


def owners(rows: list[dict]) -> list[str]:
    """Owner names, people alphabetically and Household last."""
    return sorted({T.text(g, "owner") or "?" for g in rows},
                  key=lambda n: (n == HOUSEHOLD, n.lower()))


def level(g: dict) -> int:
    parsed = parse_period(g.get("period"))
    return LEVELS[parsed[0]] if parsed else 9
```

```python
def parent_loops(goals: dict) -> list[list[str]]:
    loops, seen = [], set()
    for g in goals.values():
        trail, k = [], key(g)
        while k in goals and k not in trail:
            trail.append(k)
            k = parent_key(goals[k])
        if k in trail:
            cycle = trail[trail.index(k):]
            if frozenset(cycle) not in seen:
                seen.add(frozenset(cycle))
                loops.append([title(goals[x]) for x in cycle + [k]])
    return loops
```

```python
# --- carry --------------------------------------------------------------------

def carry(g: dict, to: str, goals: dict, tasks: dict) -> Path:
    """Copy an unfinished goal into a later period of the same length: the old
    one becomes `partial`, open tasks move to the new one (recurring ones count
    toward both), and both goals note the other."""
    old_period = parse_period(g.get("period"))
    new_period = parse_period(check_period(to))
    if not old_period or old_period[0] != new_period[0] or new_period[1] <= old_period[1]:
        kind = old_period[0] if old_period else ""
        sys.exit(f"--to must be a later {kind} period than {g.get('period')}, got {to!r}")
    today = dt.date.today().isoformat()
    old = g["_path"].stem
    lines, body = T.split(g["_path"].read_text(encoding="utf-8"))
    path = new_goal_path(title(g), to)
    stamp = T.now()
    for k, value in (("period", to), ("status", "active"), ("completedDate", None),
                     ("dateCreated", stamp), ("dateModified", stamp)):
        lines = T.set_key(lines, k, value)
    parent = goals.get(parent_key(g))
    if parent is not None and not contains(str(parent.get("period") or ""), to):
        lines = T.set_key(lines, "parent", None)
        print(f"note: no longer under {title(parent)} ({parent.get('period')}), "
              f"which does not contain {to}")
    description = re.split(r"^## ", body, maxsplit=1, flags=re.M)[0].strip("\n")
    new_body = "\n" + (description + "\n" if description else "")
    new_body = T.add_entry(new_body, "Notes",
                           f"- {today}: carried over from [[{old}]] ({g.get('period')})")
    new_body = T.add_log(new_body, f"created for {to}, carried over from [[{old}]]")
    T.new_page(path, lines, new_body)
    change = {"status": "partial"} if (g.get("status") or "active") == "active" else {}
    save(g["_path"], change, f"carried over to [[{path.stem}]]")
    T.edit_body(g["_path"], lambda b: T.add_entry(
        b, "Notes", f"- {today}: carried over to [[{path.stem}]] ({to})"))
    moved = 0
    for t in tasks.values():
        if old.lower() not in goal_links(t):
            continue
        if t.get("status") in T.CLOSED and not t.get("recurrence"):
            continue  # finished work stays with the period it was done in
        refs = T.as_list(t.get("projects"))
        if t.get("recurrence"):
            refs = refs + [T.link(path.stem)]
        else:
            refs = [T.link(path.stem) if T.name_of(r).lower() == old.lower() else r for r in refs]
        T.update(t["_path"], {"projects": refs}, f"goal carried over to [[{path.stem}]]")
        moved += 1
    print(T.rel(path))
    if moved:
        print(f"{moved} open task(s) now count toward {path.stem}")
    return path


def cmd_goal_carry(args) -> None:
    goals = index_goals()
    carry(find_goal(args.goal, goals), args.to, goals, T.index_tasks())
```

```python
def goal_lines(g: dict, goals: dict, tasks: dict, kind: str) -> list[str]:

    return [row[-1] for row in sorted(rows)]


def slipped(first: dt.date, last: dt.date, keys: set[str], tasks: dict, goals: dict) -> list[str]:
    """Open one-off tasks of these goals that were scheduled or due in the period."""
    out = []
    for t in linked_tasks(keys, tasks):
        if t.get("status") in T.CLOSED or t.get("recurrence"):
            continue
        for k in ("due", "scheduled"):
            d = T.day(t.get(k))
            if d and first <= d <= last:
                toward = ", ".join(title(goals[n]) for n in sorted(goal_links(t) & keys))
                out.append(f"- {T.title_of(t)} ({k} {d.isoformat()}) → {toward}")
                break
    return sorted(out)


def journal_lines(first: dt.date, last: dt.date, names: list[str]) -> list[str]:
    """Journal entries in the period that mention one of these goals or tasks."""
    low = [n.lower() for n in names if n]
    out, d = [], first
    while d <= last:
        path = T.journal_path(d)
        if path.exists():
            for line in T.split(path.read_text(encoding="utf-8"))[1].splitlines():
                if line.startswith("- ") and any(n in line.lower() for n in low):
                    out.append(f"- [[{d.isoformat()}]] {line[2:].strip()}")
        d += dt.timedelta(days=1)
    return out


def review_text(period: str, goals: dict, tasks: dict) -> str:
    kind, first, last = parse_period(period)
    mine = [g for g in goals.values() if str(g.get("period")) == period]
    keys = {key(x) for g in mine for x in tree(g, goals)}
    out = ["## Goals"]
    if not mine:
        out += ["", "(no goals for this period)"]
    for owner in owners(mine):
        out += ["", f"### {owner}"]
        for g in sorted((g for g in mine if (T.text(g, "owner") or "?") == owner),
                        key=lambda g: title(g).lower()):
            out += goal_lines(g, goals, tasks, kind)
    if kind == "month":
        years = sorted((g for g in goals.values() if str(g.get("period")) == str(first.year)),
                       key=lambda g: title(g).lower())
        if years:
            out += ["", f"## Year so far ({first.year})"]
            out += [f"- {title(g)} · {summary(g, progress(g, goals, tasks))}" for g in years]
    if kind == "year":
        cells = []
        for m in range(1, 13):
            months = [g for g in goals.values() if str(g.get("period")) == f"{first.year}-{m:02d}"]
            if months:
                won = sum(1 for g in months if g.get("status") == "achieved")
                cells.append(f"{dt.date(first.year, m, 1):%b} {won}/{len(months)}")
        out += ["", "## Month by month", " · ".join(cells) or "(no month goals)"]
    done = finished_in(first, last, tasks, goals)
    out += ["", f"## Done this {kind} ({len(done)} task{'s' if len(done) != 1 else ''})"]
    out += done or ["(nothing finished)"]
    out += ["", "## Slipped"] + (slipped(first, last, keys, tasks, goals) or ["(nothing)"])
    if kind != "week":
        names = [title(goals[k]) for k in keys] + [T.title_of(t) for t in linked_tasks(keys, tasks)]
        out += ["", "## From the journal"]
        out += (journal_lines(first, last, names) if names else []) or ["(nothing about these goals)"]
    return "\n".join(out)


def verdicts(content: str) -> list[tuple[str, str]]:
    """(goal name, verdict word) for each `- Name: verdict` line under ## Verdicts."""
    match = re.search(r"^## Verdicts\s*$", content, flags=re.M)
    if not match:
        return []
    rest = content[match.end():]
    nxt = re.search(r"^## ", rest, flags=re.M)
    out = []
    for line in (rest[:nxt.start()] if nxt else rest).splitlines():
        v = re.match(r"^- ([^:]+):\s*(.*?)\s*$", line)
        if v:
            word = re.match(r"[A-Za-z-]*", v.group(2)).group(0).lower()
            out.append((v.group(1).strip(), word))
    return out


def verdict_line(g: dict) -> str:
    status = g.get("status") or "active"
    return f"- {title(g)}: {status if status != 'active' else ''}".rstrip()


def write_review(period: str) -> Path:
    goals, tasks = index_goals(), T.index_tasks()
    kind = parse_period(period)[0]
    block = f"{START}\n{review_text(period, goals, tasks)}\n{END}"
    mine = sorted((g for g in goals.values() if str(g.get("period")) == period),
                  key=lambda g: title(g).lower())
    path = T.REVIEWS / f"{period}.md"
    if not path.exists():
        lines = (T.render("period", period) + T.render("type", "review")
                 + T.render("created", dt.date.today().isoformat()) + T.render("tags", ["review"]))
        body = (f"\n{heading(period)}\n\n{block}\n\n## Verdicts\n"
                + "".join(verdict_line(g) + "\n" for g in mine)
                + f"\n## What worked / what didn't\n\n## Next {kind}\n")
        T.new_page(path, lines, body)
        return path
    content = path.read_text(encoding="utf-8")
    if GENERATED.search(content):
        content = GENERATED.sub(lambda _: block, content, count=1)
    else:

    path.write_text(content, encoding="utf-8")
    return path
```

```python
def apply_verdicts(period: str) -> None:
    """Each `- Goal: verdict` under ## Verdicts becomes that goal's status;
    still-active goals are then offered for carrying into the next period
    (asked when run in a terminal, printed as commands otherwise)."""
    path = T.REVIEWS / f"{period}.md"
    goals = index_goals()
    mine = {T.squash(title(g)): g for g in goals.values() if str(g.get("period")) == period}
    for name, verdict in verdicts(path.read_text(encoding="utf-8")):
        if not verdict:
            continue
        g = mine.get(T.squash(name))
        if g is None:
            print(f"warning: no {period} goal called {name!r}; line skipped", file=sys.stderr)
            continue
        if verdict not in VERDICTS:
            print(f"warning: {name}: {verdict!r} is not one of {', '.join(VERDICTS)}; line skipped",
                  file=sys.stderr)
            continue
        before = g.get("status") or "active"
        if before == verdict:
            continue
        save(g["_path"], {"status": verdict}, f"verdict from Reviews/{period}")
        g["status"] = verdict
        print(f"{title(g)}: {before} -> {verdict}")
    still = sorted((g for g in mine.values() if (g.get("status") or "active") == "active"),
                   key=lambda g: title(g).lower())
    if not still:
        return
    kind, _, last = parse_period(period)
    following = period_of(kind, last + dt.timedelta(days=1))
    if sys.stdin.isatty():
        for g in still:
            answer = input(f"carry {title(g)!r} over to {following}? [y/N] ").strip().lower()
            if answer.startswith("y"):
                goals = index_goals()
                carry(goals[key(g)], following, goals, T.index_tasks())
    else:
        print(f"still active ({len(still)}); to carry them over to {following}:")
        for g in still:
            print(f'  tasks.py goal carry "{g["_path"].stem}" --to {following}')
```
